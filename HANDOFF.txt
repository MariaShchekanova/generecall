LOCAL SETUP — ABOUT TWO MINUTES

1. Install Node.js 22 or newer if needed. The standard Node installer includes npm.
   Check:

   node --version
   npm --version

2. Clone the repository and open the folder containing package.json in a
   terminal or code editor. No npm install is necessary: there are no dependencies.

3. Start the app:

   npm start

4. Open http://127.0.0.1:4317 and click Open demo case.
   Keep the terminal running. Stop the server with Ctrl+C when finished.

5. Check and build the source before sharing a changed version:

   npm test
   npm run build

Equivalent commands are node scripts/serve.mjs, node --test
src/engine.test.mjs src/server.test.mjs src/ui.test.mjs, and node scripts/build.mjs.
Portable launchers are included for macOS (.command) and Windows (.cmd).
After editing the HTML, refresh the browser. After editing backend modules or
environment settings, restart the server as well.

OPTIONAL LIVE AI

The demo and evidence parser work without an OpenAI key. To enable live extraction,
create your own .env.local alongside package.json, using .env.example as a guide:

   OPENAI_API_KEY=<your own key, entered locally>
   OPENAI_MODEL=gpt-5-mini
   PORT=4317

Restart the server after changing environment values. Never paste a secret into
chat, commit it, put it in frontend code, or include it in a handoff archive.
.env.local is ignored by Git. Keep credentials server-side.

ARCHITECTURE

Browser UI → local Node HTTP adapter → shared request router → explicit evidence
logic and optional OpenAI / NCBI requests.

The frontend is a single self-contained HTML/CSS/JavaScript file. The same core
router can run locally or in the generated Cloudflare Worker. There is no database,
package dependency, frontend framework, or external build tool.

API SURFACE

GET /api/config
  Reports configuration state. It returns no secret and does not spend an AI
  request to test credentials.

GET /api/demo
  Returns the fictional report, real dated snapshot, comparison, and draft.

POST /api/parse
  Takes a text excerpt and attempts optional AI extraction when enabled; otherwise
  returns conservative parsing with an explicit engine/fallback label.

POST /api/compare
  Takes the text, user-reviewed report fields, exact accession, and confirmed:true.
  Retrieves the exact ClinVar record and returns evidence, comparison, and draft.
  The demo can use the dated same-variant snapshot when its live lookup fails.

Treat report text and provider output as untrusted input. Preserve source checks,
identifier checks, safe DOM rendering, length limits, and honest fallback messages
when refactoring. Read the source for full request and response field contracts.

DATA AND PRIVACY BOUNDARIES

The app does not intentionally save report text to a database, localStorage, or
application logs. Processing happens in server memory and browser state. A page
refresh or reset clears the working UI; this is not a durable patient record.
Exports saved by the person remain on their computer.

If AI extraction is enabled, the submitted excerpt is sent to OpenAI with
store:false. That flag is not a promise of zero provider retention; providers and
hosting infrastructure have their own policies. The ClinVar lookup uses the exact
public variation ID. There is no automatic sending of the letter.

The prototype has no authentication, multi-user isolation, formal privacy review,
or established clinical deployment process. Keep development/demo material
synthetic. Adding accounts, real patient storage, or public hosting requires a
deliberate design for access, consent, retention, and deletion.

• Try narrow/mobile width, keyboard navigation, and a long excerpt.
• If AI is part of the presentation, test a real request with your own funded key.
  Show the provider/fallback state truthfully if it is unavailable.

KNOWN SCOPE LIMITS

Only one selected variant and text/.txt input are supported. The conservative
parser expects recognizable labeled fields and may need manual corrections.
The app does not infer a historical reclassification from two different sources,
resolve conflicting submissions, diagnose, or recommend treatment. The demo's
prior VUS label is invented; the real ClinVar evidence does not validate that
invented history. External providers can time out or be unavailable.
